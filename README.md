# Customer Shopping Behavior & Purchase Pattern Analysis

## Project Overview
This project analyzes customer shopping behavior and purchasing patterns using Python, PostgreSQL, Excel, and Power BI. The goal is to understand customer preferences, spending habits, product performance, discount usage, and purchasing frequency through data analysis and visualization.

## Dataset
- **Dataset:** `customer_shopping_behavior.csv`
- **Total Records:** 3,900
- **Original Columns:** 18
- **Final Cleaned Columns:** 19

## Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- PostgreSQL
- SQL
- Excel
- Power BI

## Project Workflow

1. **Data Collection:** Imported the customer shopping behavior dataset.
2. **Data Cleaning:** Handled missing values, renamed columns, removed duplicate information, and performed data preprocessing using Python.
3. **Exploratory Data Analysis:** Analyzed customer demographics, spending patterns, product preferences, and purchase frequency.
4. **SQL Analysis:** Used PostgreSQL to perform business analysis and extract meaningful insights.
5. **Data Visualization:** Used Power BI to create interactive dashboards and visualize key findings.

## Key Business Questions
- Which gender generates the highest revenue?
- Which products have the highest average ratings?
- How do discounts influence customer purchases?
- What is the spending behavior of subscribers and non-subscribers?
- Who are the new, returning, and loyal customers?
- Which products are most popular within each category?
- What are the customer purchasing patterns?

## Key Insights
The project explores customer spending behavior, product performance, discount trends, subscription patterns, customer segmentation, and purchasing frequency to identify useful business insights.

## Project Objectives
- Understand customer purchasing behavior.
- Identify popular products and categories.
- Analyze revenue and spending trends.
- Explore customer segments and preferences.
- Support data-driven business decisions through visualization.

## Tools & Applications
- Python for data cleaning and EDA.
- PostgreSQL for database management and SQL queries.
- Excel for data inspection.
- Power BI for interactive dashboards.

## Conclusion
This project demonstrates an end-to-end data analytics workflow, from raw data cleaning to SQL-based analysis and dashboard development. It helps transform raw customer data into meaningful insights that can support better business decisions.
